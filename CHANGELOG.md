# Changelog

## 1.0.0-SNAPSHOT — Unreleased

- Added the Java 25 Maven reactor with Spring-free core, Boot 3.5.16 autoconfiguration, dependency-only starter, and safe demonstration application.
- Added SQL injection, XSS, SpEL, path traversal, command, LDAP, NoSQL, and XML external-entity request screening strategies.
- Added configurable MONITOR/BLOCK/STRICT policies, bounded input processing, request exemptions, servlet body replay, and annotated argument scanning.
- Added metadata-oriented threat events/logging, optional Micrometer/health integration, and optional asynchronous webhook alerting.
- Added detector/security regression tests, auto-configuration and servlet acceptance tests, JaCoCo library coverage enforcement, and opt-in core performance characterization.
- Added non-root container packaging, local-only demo Compose service, Java 25 CI, configuration/usage guidance, and explicit security/support limitations.

This is an unreleased project version; no Maven Central publication, independent security audit, or production performance certification is asserted.
